## Problem Statement

업무운영팀 담당자는 예전에 등록했던 기준가 데이터를 다시 확인하고 싶을 때가 있는데, 지금은 특정 날짜나 특정 펀드의 데이터만 골라서 찾아볼 방법이 없다.

## Solution

날짜별로, 또는 펀드코드나 펀드명으로 등록 이력을 검색해서 볼 수 있는 화면을 제공한다. 원하는 열 기준으로 정렬도 할 수 있어서, 필요한 데이터를 빠르게 찾을 수 있다.

## User Stories

1. As a 업무운영팀 담당자, I want 특정 날짜를 선택해서 그날 업로드·등록된 기준가 데이터를 보는 것, so that 예전 특정 날짜의 데이터를 다시 확인할 수 있다.
2. As a 업무운영팀 담당자, I want 기간(시작일~종료일)을 지정해서 여러 날짜의 데이터를 한 번에 보는 것, so that 특정 기간 동안의 흐름을 볼 수 있다.
3. As a 업무운영팀 담당자, I want 펀드코드를 입력해서 그 펀드의 등록 이력만 보는 것, so that 특정 펀드의 기준가 변화를 추적할 수 있다.
4. As a 업무운영팀 담당자, I want 펀드명을 일부만 입력해도 관련된 펀드가 검색되는 것, so that 정확한 이름을 몰라도 찾을 수 있다.
5. As a 업무운영팀 담당자, I want 날짜, 펀드코드, 펀드명 조건을 같이 적용해서 좁혀서 찾는 것, so that 원하는 데이터를 더 빠르게 찾을 수 있다.
6. As a 업무운영팀 담당자, I want 표의 각 열(날짜, 펀드코드, 기준가 등) 제목을 클릭하면 그 기준으로 정렬되는 것, so that 원하는 순서로 데이터를 볼 수 있다.
7. As a 업무운영팀 담당자, I want 같은 열을 다시 클릭하면 오름차순/내림차순이 바뀌는 것, so that 필요에 따라 순서를 뒤집어 볼 수 있다.
8. As a 업무운영팀 담당자, I want 각 항목이 정상 등록된 것인지 이상으로 제외됐던 것인지 표시로 구분되는 것, so that 이력만 봐도 그날 상태를 알 수 있다.
9. As a 업무운영팀 담당자, I want 조회 결과가 많을 때 페이지를 나눠서 보는 것, so that 한 화면에 너무 많은 데이터가 몰려서 찾기 힘들지 않다.
10. As a 업무운영팀 담당자, I want 필터를 초기화하는 버튼, so that 처음부터 다시 조건 없이 검색할 수 있다.
11. As a 업무운영팀 담당자, I want 아무 조건도 입력하지 않고 화면을 열면 최근 등록 데이터가 먼저 보이는 것, so that 굳이 검색하지 않아도 최근 상황을 바로 볼 수 있다.
12. As a 업무운영팀 담당자, I want 검색 조건에 맞는 데이터가 하나도 없을 때 "결과 없음"이라고 명확히 보이는 것, so that 결과가 없는 건지 아직 로딩 중인 건지 헷갈리지 않는다.

## Implementation Decisions

- 새 API `GET /api/price-records`: 아래 쿼리 파라미터를 지원한다.
  - `date`(특정 기준일자) 또는 `from`/`to`(기간) — `price_date`와 같은 `'20260914'` 형태의 `YYYYMMDD` 문자열로 주고받는다.
  - `fnd_cod`(정확히 일치 또는 부분 일치)
  - `fnd_nm`(부분 일치, LIKE 검색)
  - `sort`(`price_date` | `fnd_cod` | `fnd_nm` | `tr_bpr` | `status`), `order`(`asc` | `desc`, 기본은 `price_date` 내림차순)
  - `page`, `page_size`(기본 50건)
  - `price_records`와 `price_uploads`를 조인해서 업로드일·원본 파일명도 함께 조회 가능하게 한다.
- 새 페이지 `/price-history`: 상단에 날짜/기간, 펀드코드, 펀드명 입력 필터와 검색·초기화 버튼을 두고, 결과 표는 열 제목 클릭으로 정렬 방향을 토글한다. 상태 컬럼은 기준가-데이터-확인및등록 기능에서 쓰는 Badge 색상 체계(정상/이상/등록완료)를 그대로 사용한다.
- 조건 없이 처음 열었을 때는 필터 없이 최근 `price_date` 순으로 최신 50건을 보여준다.
- `app/layout.tsx`의 nav에 이 페이지로 가는 링크를 추가한다.

## Out of Scope

- 조회 결과를 엑셀/CSV 등 파일로 내보내는 기능.
- 실시간으로 화면이 자동 갱신되는 기능 — 검색·새로고침 시점에만 최신 데이터를 보여준다.
- 이 화면에서 데이터를 직접 수정하는 기능 — 조회 전용이다.

## Further Notes

- 이 기능은 새 테이블을 만들지 않고, 기준가-파일-업로드·기준가-데이터-확인및등록 기능에서 정의한 `price_uploads`/`price_records` 테이블을 조회만 한다.
