# ADR-0005 — 등록 이력 조회 화면은 검색·새로고침 시점에만 최신 데이터를 반영한다

## 맥락

기준가 데이터는 펀드 평가사가 매일 아침 한 번 보내주고 담당자가 그 시점에 등록하는
흐름이라, 이력 조회 화면이 실시간으로 계속 갱신되어야 할 업무적 필요가 크지 않다.

## 버린 대안

- **폴링이나 웹소켓 등으로 화면을 실시간 자동 갱신하는 안** — 하루 한 번 등록되는 데이터
  특성상 구현 비용 대비 실익이 적어 제외했다.

## 결과

담당자가 화면을 열어둔 채로 다른 곳에서 등록이 일어나도 바로 반영되지 않고, 직접
재검색하거나 새로고침해야 최신 상태를 볼 수 있다.
