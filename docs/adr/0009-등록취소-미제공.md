# ADR-0009 — 등록 완료된 항목은 취소하거나 되돌릴 수 없다

## 맥락

등록은 기준가 데이터가 펀드 운용시스템에 최종 반영되는, 업무상 처리가 끝나는 지점이라
등록 이후 값을 되돌리는 것은 이미 다른 곳에서 쓰인 데이터를 되돌리는 문제와 얽힌다.

## 버린 대안

- **등록 취소·롤백 기능을 이 도구에서 제공하는 안** — 이미 반영된 값의 정합성을 이
  도구가 책임지기 어려워 기각했다.

## 결과

잘못 등록된 값을 고치려면 이 도구가 아니라 펀드 운용시스템에서 직접 정정해야 한다.
