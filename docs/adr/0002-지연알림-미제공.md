# ADR-0002 — 기준가 파일 지연·미수신에 자동 알림을 보내지 않는다

## 맥락

펀드 평가사가 매일 아침 기준가 파일을 보내는 흐름에서, 파일이 늦거나 오지 않는 경우는
드물게 발생한다. 담당자가 "오늘의-등록-현황" 화면을 열어야 지연 여부를 알 수 있다.

## 버린 대안

- **이메일·메신저 자동 알림** — 파일 지연·누락이 드물어, 알림 인프라를 구축하는 비용 대비
  효용이 낮다고 판단해 제외했다.

## 결과

담당자가 화면을 직접 열어봐야만 오늘 파일이 늦었는지 알 수 있고, 시스템이 능동적으로
알려주지 않는다.
