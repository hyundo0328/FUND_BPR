# ADR-0001 — 구현 범위

업무운영팀 담당자가 매일 아침 펀드 평가사로부터 받은 기준가 txt 파일을 확인하고 사내 펀드
운용시스템에 등록하는 업무를, 파일 업로드부터 이상값 확인·등록·현황 파악·이력 조회까지
하나의 도구로 지원한다.

## 커버리지

| 업무 단계 | 커버 | 남는 사람 몫 |
|---|---|---|
| 기준가 파일 수신 확인 | 부분 | 메일을 열어 파일을 내려받고 도구에 직접 올리는 것은 사람이 한다 (메일함 자동 접속은 범위 밖) |
| 파일 내용 구분자 분리·저장 | 시스템 | — |
| 값 이상 여부 1차 판정 | 시스템 | 1차 규칙(값 없음, 거래기준가 비정상)을 통과한 값이 실제로도 맞는지는 사람이 최종 판단 |
| 이상 항목 재확인 요청 | 없음 | 평가사에게 연락해 재확인을 요청하는 것은 담당자가 직접 한다 |
| 펀드 운용시스템 등록 | 시스템 | — |
| 오늘 처리 현황 파악 | 시스템 | — |
| 과거 이력 조회 | 시스템 | — |

## 해석에 영향을 주는 제외

- **1차 이상 판정 기준의 범위** — `이상` 표시가 없는(`pending`/`registered`) 항목은 값이
  비어있지 않고 거래기준가가 숫자이며 0보다 크다는 것만 확인된 상태다. "전일 대비 급격한
  변동" 같은 통계적 이상은 걸러내지 않으므로, 이상 표시가 없다고 해서 값이 실제로 맞다는
  뜻은 아니다.

## 검증되지 않는 것

- **화면 표시·화면 간 이동** — 테스트 seam이 API route라 자동 검증되지 않는다.
  서버가 무엇을 내려주는지는 테스트가 잠그지만, 그것을 화면에 어떻게 그리는지는 사람이 열어 확인한다.
