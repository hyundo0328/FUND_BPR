# ADR-0008 — 이상 항목의 값은 화면에서 직접 수정하지 않고 재업로드로만 정정한다

## 맥락

값 없음·거래기준가 이상으로 판정된 항목은 펀드 평가사가 산출한 원본 데이터의 문제이며,
담당자가 임의로 고치면 평가사가 실제로 재산출한 값과 어긋날 위험이 있다.

## 버린 대안

- **화면에서 이상 항목 값을 바로 고칠 수 있는 인라인 편집 기능** — 평가사 확인 없이 값이
  바뀔 수 있어 기각했다.

## 결과

정정은 항상 평가사의 재확인과 재업로드를 거쳐야 하며, 담당자가 화면에서 즉시 값을 고쳐
등록을 끝낼 수는 없다.
