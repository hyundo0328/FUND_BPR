# ADR-0006 — 등록 이력 조회 화면은 조회 전용이며 데이터를 직접 수정할 수 없다

## 맥락

기준가 데이터를 확인하고 등록하는 책임은 이미 기준가-데이터-확인및등록 기능이 담당하고
있어, 이력 조회 화면은 지나간 데이터를 다시 찾아보는 용도로 한정했다.

## 버린 대안

- **조회 화면에서도 값을 바로 고칠 수 있게 하는 안** — 확인및등록 기능과 수정 책임이
  겹치게 되고, 이미 등록된 이력 데이터의 무결성 관리가 복잡해져 제외했다.

## 결과

담당자가 이력을 보다가 잘못된 값을 발견해도 이 화면에서 바로 고치지 못하고, 별도 절차나
다른 기능을 통해 수정해야 한다.
