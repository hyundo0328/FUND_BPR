# ADR-0007 — 오늘의-등록-현황·등록-이력-조회는 새 테이블 없이 price_uploads/price_records를 그대로 조회한다

## 맥락

기준가-데이터-확인및등록 기능이 이미 매일 등록되는 기준가 데이터를 `price_uploads`/
`price_records`에 쌓아두고 있어, 오늘 현황 파악과 이력 조회에 필요한 데이터가 이미 그
안에 존재한다.

## 버린 대안

- **조회 전용의 별도 이력/집계 테이블을 새로 만드는 안** — 이미 존재하는 데이터를
  중복해서 별도로 관리해야 하는 부담과 동기화 문제가 생겨 제외했다.

## 결과

이 두 조회 기능은 기준가-데이터-확인및등록 기능의 스키마 변경에 직접 영향을 받으며,
조회 성능이나 이력 보존 방식을 독립적으로 조정할 수 없다.
