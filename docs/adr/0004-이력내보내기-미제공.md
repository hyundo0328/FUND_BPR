# ADR-0004 — 등록 이력 조회 결과를 엑셀·CSV로 내보내는 기능을 제공하지 않는다

## 맥락

업무운영팀 담당자가 예전 기준가 등록 이력을 화면에서 검색해 다시 확인할 수 있게 하는 것이
이 기능의 목적이며, 조회된 데이터를 외부로 반출하는 것까지는 이번 범위에 포함하지 않았다.

## 버린 대안

- **엑셀/CSV 내보내기 기능을 함께 구현하는 안** — 조회 화면 자체의 목적(다시 확인하기)을
  넘어서는 추가 기능이라 이번 범위에서 제외했다.

## 결과

담당자가 조회 결과를 다른 곳에 공유하거나 가공하려면 화면 밖에서 수동으로 처리해야 한다.
