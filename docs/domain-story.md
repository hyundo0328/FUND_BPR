# 펀드 기준가 데이터 등록 업무

## 상황

업무운영팀 담당자가 매일 아침 펀드 평가사로부터 받은 기준가 데이터를 사내 펀드 운용시스템에 등록하는 상황.

## 등장인물

- **업무운영팀 담당자(본인)** — 기준가 파일을 받아 확인하고 펀드 운용시스템에 등록하는 사람
- **펀드 평가사** — 매일 아침 기준가 데이터를 이메일로 보내주는 외부 기관
- **펀드 운용시스템** — 업무운영팀이 지원(운영)하는 사내 시스템으로, 기준가 데이터가 최종 등록되는 곳

## 오가는 것

- **기준가 txt 파일** — 펀드 평가사가 매일 아침 이메일 첨부로 보내는 파일, 구분자로 값들이 나뉘어 있음
- **구분자로 분리된 기준가 데이터** — txt 파일을 구분자 기준으로 나눈 데이터
- **등록된 기준가** — 펀드 운용시스템에 최종 입력된 데이터

## 흐름

1. 펀드 평가사가 기준가 txt 파일을 매일 아침 이메일로 보낸다.
2. 담당자가 이메일을 받아 파일을 확인한다.
3. 담당자가 txt 파일을 구분자로 분리해서 데이터를 저장한다.
4. 담당자가 그 데이터를 사내 펀드 운용시스템에 등록한다.

## 예외

- 파일이 제때 오지 않거나 아예 오지 않는 경우 → 거의 없음 (드문 경우)
- 파일 내 기준가 데이터 중 일부가 빠져있거나 값이 이상한 경우 → 펀드 평가사에 다시 확인을 요청한다

## 끝나는 지점

그날 받은 기준가 데이터가 펀드 운용시스템에 정상적으로 등록되면 끝. 별도로 등록 완료를 보고하는 절차는 없음.

## 지금의 불편함

- 파일이 제때 왔는지 확인하는 것이 번거롭다
- 파일을 직접 등록해줘야 하는 것이 불편하다

## 용어

| 용어 | 뜻 |
|---|---|
| 기준가 | 펀드 평가사가 산출해서 매일 보내주는 펀드의 기준가격 데이터 |
| 펀드 운용시스템 | 업무운영팀이 지원(운영)하는 사내 시스템, 기준가 데이터가 등록되는 곳 |
